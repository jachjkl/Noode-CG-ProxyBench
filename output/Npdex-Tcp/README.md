# Shared direct subscription

`Tls.txt` is the single public subscription for both direct TCPing and direct TLS selection. Each successful publication replaces it with the latest competition-tested ranked list, using the owner's saved ordinary and Japanese counts. Lines retain `IP:port#COUNTRY` format. It is byte-for-byte identical to the compatibility text in `output/Nodes-TCP/nodes.txt`; detailed metrics and health remain in that compatibility namespace. Publishing proxy results cannot modify this file. An unsuccessful run preserves the last confirmed list.
