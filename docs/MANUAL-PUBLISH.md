# Manual publication and timers

Stop-and-save preserves completed measurements and checkpoints without publishing. Manual push queues final competition after the current batch, or starts one owned publisher while idle. It uses already measured candidates, runs fresh quality tests, and selects up to the ordinary and additional Japanese counts saved for that method. It does not acquire unmeasured candidates. Partial qualified output is explicitly marked and checked by the cloud decoder. Automatic publication still requires the complete configured quotas.

The timer records optimization time; pause/stop freezes it, resume continues, and a new optimization resets it. Window lifetime is displayed separately. Method rules and selected mode persist, while normal closure removes candidate/checkpoint caches. Errors, interruption and deliberate stop preserve recovery state. Chinese logs, saved settings and published files persist.
